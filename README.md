# Yuvraj K — Portfolio

Professional, zero-dependency portfolio site.

## Run locally

```bash
npx serve .
```

Or open `index.html` directly in a browser.

## Deploy

- **GitHub Pages**: push to `Yuvrajbhagyedh.github.io` and enable Pages on `main`
- **Vercel / Netlify**: drop this folder in

## Files

- `index.html` — content, projects, links
- `styles.css` — cool stone & sapphire theme
- `script.js` — progress bar, reveals, magnetic hover, clock
- `favicon.svg`
